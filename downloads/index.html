    Questions

    Do I need to unzip the file first?

    Yes. Pacon downloads as a ZIP. Unzip it, open the extracted folder and run the installer inside. Running the installer from inside the ZIP can fail.

    How do I check the download is genuine?

    Compare the SHA-256 checksum above with your file. On macOS and Linux run shasum -a 256 <file>; on Windows run certutil -hashfile <file> SHA256. The two values must match exactly.

    Does Pacon upload my files?

    No. Files are scanned on your device. Only the name and fingerprint of a suspicious file are checked against our threat database, and you can turn this off in Settings.

    Can I run Pacon next to another antivirus?

    Two real-time scanners can slow your device and conflict. Uninstall your current antivirus before you install Pacon, then restart.

    How do I uninstall it?

    Open your system's list of installed apps, choose Pacon Antivirus and select Uninstall. Restart your device when it finishes.
